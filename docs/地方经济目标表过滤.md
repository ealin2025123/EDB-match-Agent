# 地方经济目标表过滤

本工作流只接收目标表 `usrDFJJYXSJB`。使用 workflow_nodes/DC_地方经济前置过滤.py，放在开始之后、规则库查询和Agent接入之前。

连接顺序：开始 → 地方经济前置过滤 → 条件判断（continue_workflow 等于 true）→ 原文件类型路由及处理链；false 连接直接结束分支。跳过属于正常过滤，不作为Agent失败，不进行重试或标注。

输入优先映射开始记录的 `sourceDataInfo.fields.data_target_table.value` 到脚本的 `data_target_table`。也可直接传入完整开始事件，脚本兼容顶层字符串、带value的字段对象及嵌套fields。

输出映射：continue_workflow和skip_workflow为Boolean，data_target_table、filter_status、filter_reason为String。只检查明确的目标表名；不以地方经济标签、标题或页面路径代替。字段缺失、无效或多处值冲突均跳过并说明映射问题。

只增加前置分流，不改变已通过记录的单位换算、清洗、内审及标注逻辑。不把data_target_table发送到Agent HTTP接口，后者当前不接受此字段。原有开始字段继续沿原工作流传递，此过滤节点的输出仅供条件判断。
