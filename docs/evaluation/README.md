# 小样本评测过程与结果

本目录记录2026年11月6日的独立评测实验，不是生产Agent消融实验，也未执行DC实测。

## 演进路线

起初希望生成代码替代人工解析；随后加入匹配与审核来判断效果；发现低匹配也可能来自文件或GZK问题，因此增加前置校验；最后复用已有资产以减少重复生成。

## 过程

1. 构造Excel、HTML、Prompt三个分支，每类简单、中等、复杂各两个期间，共18个合成样本、36条目标记录。它们来自同一个财政模板的变体。
2. Gold结合实际源表/正文完成AI复核，未冒充人工签收。规则中存在但源文未公布的支出不计入覆盖率分母。
3. 固定源数据与规则，先生成并执行A；B/C共享A的初始结果，分别追加审核修复、预审与审核；D重放A的原始资产。不是四组独立随机实验。
4. 真实调用现有DeepSeek后端，保留每轮结果、调用次数、Token和重建次数。首轮8192输出上限截断后另起试跑；正式批次采用32768预算，不混合两次试跑。
5. 加入6个异常检查和2个单位换算评分边界，共26场景。允许41.82亿元与418200万元等价；错误换算比例不接受。
6. 汇总18个任务的固定分母，单列失败和依赖跳过，取消DC实测。

## 文件

- [报告](report-26.md)与[汇总](summary-26.json)：实际结果和适用边界。
- synthetic-sources.json：18个合成源的实际读取内容、Gold和来源哈希，不包含企业原始文件。
- A/B/C/D四个JSON：72条阶段观测，包含成功、失败、评分、消耗与依赖关系。个人本机路径已脱敏。
- scripts/rescore.py：离线重新计算评分，不调用模型或下载文件。

## 复核

在仓库根目录执行 `python docs/evaluation/scripts/rescore.py`。它重新计算72条观测中实际返回的候选；环境失败与依赖跳过单列。源材料为规范化的读取快照，不是原始Excel二进制，因此来源哈希不能拿JSON快照直接重算。

模型生成实验的完整执行入口仍在本机评测目录，本次上传报告、合成材料、观测证据和可复现评分程序。没有声称一条命令可以重现相同模型生成结果。

## 不能据此宣称

不能将门禁测试通过率算成提取准确率；不能将同输入资产重放算成跨期缓存命中率；关键错误注入未完成，错误放行率未测。主要失败含实验室接口不兼容，不能外推生产准确率。本轮未隔离验证前置校验的因果收益。
