## 原因与处理

旧代码导入html或访问HTMLParser私有字段，违反当前worker约束。修复只把报错、原始源内容、GZK、旧代码及真实允许模块反馈给模型，不把Gold发给模型，也不人工改写业务解析代码。每个样本最多两次重建。
空提取案例优先回放原B/C已经审核通过的修复资产，不为该样本重复生成。
执行成功不自动等于质量通过：运行结束后独立对照Gold，数值、指标身份、日期以及单位等价关系须成立。
本轮没有重新执行完整B/C模型审核、HTTP交付或跨期复用，属于受当前执行器约束的资产定向修复评测。
