# 已有解析资产优先

默认先将 pageTitle 中的 `/`、`\` 转成 `_`，在本机 `EDBPythonCode-master (3)/EDBPythonCode-master` 下按类型递归查找同名资产：Excel/HTML 使用各自目录中的 `.py`，Prompt 使用 `prompt` 中的 `.md`。

该目录中的资产由用户确认可用。命中后不查询生成规则、不生成新代码或提示词、不进入重建循环。Python 只执行一次当前源文件，再做精确 GZK 匹配和结果门禁；Prompt 直接使用已有提示词调用模型提取一次，不生成提示词。保留单位、日期、至少两个不同指标、资产哈希及传输完整性校验，后续 DC 的单位换算、清洗及内审链不变。

该分支的审核依据标为 `user_confirmed_library`，不是伪造的 DeepSeek 独立语义审核结论。当前源数据和执行结果分别保存于新任务目录，原始库文件不改写。执行失败、空结果、日期缺失或匹配不足直接停止，不自动生成或修复。

同名同内容文件可折叠；同名不同内容返回 LOCAL_ASSET_AMBIGUOUS。优先查对应分类，分类未命中时到整个根目录递归查同名文件；Excel/HTML 可跨分类复用 Python。仅找到 Prompt `.md` 不代表存在可执行的 Python。旧代码是否支持当前源格式以实际执行为准，失败不会回退生成。整个根目录仍未命中时才保留原 Agent 生成流程。服务器任务模板可用 existing_parser_root 配置库根目录，prefer_existing_parsers=false 可明确关闭此优先分支；HTTP 客户端不能指定任意本机代码目录。

这项策略用于新受理的任务。既有 job_id 的成功/失败记录不改写，不自动重跑历史任务。
